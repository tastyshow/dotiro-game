# 刺绣界面与手机适配更新 v4

## 本轮修改
- 独立响应式画卷、正方形棋盘和工具栏，移除固定比例整页缩小。
- 以 visualViewport 高度更新布局，包含短屏导航页适配；theme-color 与暖色布底协调。
- 首页透明化沿用原构图，移除玩法；增加作品册与带确认的重置进度。
- 新增透明刺绣字体、按钮、关卡布扣、完成徽章；原音量与底部工具栏作为透明素材复用。
- 九宫格刺绣绳边避免纵向选关页把横向边框拉粗。
- 重玩与首次完成均在 1.9 秒后进入下一关；第六关 2.4 秒后进入欣赏页。重玩保留收藏，顶部按当前关进度重新缝合。
- 完成页、作品册提供再绣一次；首页通关后主入口直接进入选关。
- 穿布声使用短滤波噪声；猫咪层首次开始绣制时播放一次短合成猫叫，遵循声音开关。
- 保留逐针遮罩和移动针线，撤回同步回退；底部路线改用圆角细绣线。

## 浏览器证据
- Chromium 手机尺寸：375×667、390×664、390×844、430×932：正方形棋盘、实际鼠标模拟拖动、撤回、重玩第一关空白、第三关从前两关开始、收藏保留，均通过。
- 导航页：375×567、390×664、390×844、430×932：首页、选关、欣赏、作品册无水平或垂直溢出，均通过。
- 新游戏与重玩自动跳关、第六关自动完成页、再绣一次、重置取消/确认及首页无玩法，通过。
- 页面运行无 JavaScript 错误，语法检查通过。

## 验收边界
- 尚未在真实 iPhone Safari 上检查状态栏、动态地址栏与音效听感，不能声称实机验收通过。
- 系统状态栏由浏览器控制，theme-color 只协调颜色，不保证状态栏也呈现布纹。
- 声音为合成效果，非录制的真实猫叫；后续可以在实机听感反馈后换用录音。
- 仍沿用已确认的横版分层画稿；选关页按容器取景，不是另画一套章节作品。前面关卡留下的未绣布面是后续内容的位置。
- 新透明控件属于本轮实装素材，需用户确认最终视觉，不把自动检查作为视觉认可。

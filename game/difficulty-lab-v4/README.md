# 第四版：固定起点，同盘比墙

已确认设计：两组 6×6，每组无墙、四段独立直墙、两组 L 型墙。每组图案、针点、起点完全一致；两个有墙版本均为四段单位长度墙。保留第三版独立地址。

实现步骤：生成完整路线并打散；完整枚举固定起点解数；筛选无墙 2–8 解的候选；添加不破坏已知解的墙；筛选每个版本至少三处已证实无法通关、但仍可继续走至少五步的分支；保存静态题目；复核几何与所有解；浏览器点按、提示、发布验证。

`analysis.json` 记录完整解数。错误分支指标沿一条已知解统计，后续步数使用仅检查局部合法性的搜索，不代表人类必须走这些步才发现错误；有思考经验的玩家可能提前看出。它不是难度证明，墙也可能让题目更容易。解数不展示在棋盘上，避免暗示预期答案。

运行 `node build-levels.cjs` 复现，`node verify.cjs` 检查。每格至少 44px；真机误触和实际难度需试玩。

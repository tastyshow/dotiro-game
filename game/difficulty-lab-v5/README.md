# 第五版：四张固定起点挑战

已确认方案：两张 6×6、两张 7×7，固定起点、唯一解或极少解；借助图案分散、通道争用与转角墙提高规划需求。保持现有图案规则、点按/拖动、撤回、提示及独立存档。

实现计划：生成打散的满盘路线，按路线配置图案和针点；添加两个 L 墙及少量独立墙；完整枚举筛选唯一解；检查沿解路线出现的错误分支，排除已切断剩余区域、或已产生过多死端的显然错误；选择至少三处仍可合法延伸六步的错误分支；保存可重放证据；检查规则与几何，再检查浏览器及公开页面。

`analysis.json` 保存解数、搜索节点和错误分支证据。每个 witness 给出分岔位置、错误格及仍保持剩余区域连通/死端数约束的后续路线。这些只用于筛选；不证明人类必须推理这么多步，更不保证比第四版更难。没有对人类视觉识别、棋盘奇偶或图案可达性作完整建模。

`node build-levels.cjs` 复现；`node verify.cjs` 完整枚举及重放错误分支。7×7 保持至少44px格宽，小屏可用移动模式；触控舒适度须真机试玩。旧版地址保持可比较。

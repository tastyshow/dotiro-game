# DOTIRO 难度试绣小样

2026-10-10。用户授权制作可试玩的难度对照，并补充7×7、8×8及更大棋盘，前提是手机操作不容易误触。

入口：`/difficulty-lab/`（以 game 为服务根目录）。直接依赖 game/assets 中已有布纹、字标和图案，不需要构建或联网下载。

## 八张固定棋盘

1. 5×5：轻松热身，无障碍。
2. 5×5：出口选择，无障碍。
3. 6×6：棋盘扩大，无障碍。
4. 6×6：两格固定障碍。
5. 6×6：四格障碍形成中央通道。
6. 7×7：无障碍尺寸对照。
7. 8×8：无障碍尺寸对照。
8. 10×10：无障碍超大盘边界体验。

前五张以有限穷举的搜索量作筛选参考，不等于真人难度。后三张用于观察空间规模、长类别路线和操作负担，不声称严格逐张更难。每张存有合法完整路线。所有可走格必须连完；障碍不计入通关格数。

## 操作

点按相邻格或从末端拖动。拖动需进入格子中央64%的区域才触发，沿途采样，不跳格。可沿线回拖、点旧格撤回、退一针、重来和提示。不会自动切换小样，方便评价。

每格至少44 CSS像素。可视区域按窗口宽高计算；容纳不下时保持格子大小，通过明确的“移动棋盘/继续连线”模式拖动查看。移动模式不连线。此方案存在不能同时看全大棋盘的取舍，等待手机试玩反馈。

独立 localStorage 键：`dotiro.difficulty-lab.v1`。保存各小样路线、撤回/提示计数和主观评价。评价只存在当前浏览器，未上传。正式章节素材、页面和进度不变。本小样只用于玩法与尺寸判断，不展示新作品或新增美术揭晓。

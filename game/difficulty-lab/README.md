## 规则

- 固定起点，正交移动，不重复经过，走满所有格子。
- 图案类别没有指定顺序。一旦开始某类，须连完该类全部符号才可换类。
- `cells` 的数字 0–4 代表五类符号，`null` 是通用针点。
- 针点不改变当前类别，必须走完；经过针点不能绕过“同类全部连完”的限制。
- 当前类别依据路线中最后一个有类别的格子计算，撤回自动恢复。
- 完成全部图案后，仍可继续经过剩余针点，直至整盘完成。
- `walls` 是无向相邻格对，表示两格之间禁止连接，不占掉格子。
- 页面图案数量栏只展示进度，明确注明“顺序由你选”。

## 输入与存档

支持相邻点按、拖动、抬手续连、沿线回拖、点旧格撤回、退一针、重来、键盘、求解提示。拖动须进入格子中央64%才触发，沿途采样；全部可走格的热区相同，不按针点图标大小缩小。

优先显示完整棋盘，必要时页面纵向滚动。每格不低于44 CSS像素；320px窄屏收紧页边距，使7×7仍可完整显示。更窄窗口保留移动棋盘模式。

新存档键 `dotiro.difficulty-lab.v2.playtest`。每张分别保存路线、撤回/提示次数和评价。第一版备份在 `previous/`，正式游戏与第一版存档没有迁移。

## 实现与出题

- `core.js`：共享规则、邻接和有预算的求解器；UI和验证共用。
- `build-levels.cjs`：固定随机种子，生成有保证解的候选盘；筛选局部可走分岔、不同类别候选、邻接多类别的针点和经求解确认无法完成的分支。
- `levels.js`：八张固定题目，含完整解与筛选指标。
- `lab.js`：渲染、输入、持久化、提示、评价。
- `verify.cjs`：规则回归和八张完整解验证。

候选筛选指标是程序侧结构线索，不是用户难度评分；也不保证唯一解或每个关卡的类别先后必须唯一。提示搜索预算耗尽时显示“需要更多推演”，不会把未完成搜索当作无解。

重新生成：`node game/difficulty-lab/build-levels.cjs`。
验证：`node game/difficulty-lab/verify.cjs`。

## 本轮验证

- 八张完整路径全部合法、覆盖全部格；5×5均无墙。
- 检查62个通用针点经过时保持当前类；7条墙均双向拒绝。
- 每张至少存在一个局部合法但已被完整搜索证实无法完成的分支。
- 每张从中途路线启动真实搜索，所得完整解重新逐步校验。
- 专项覆盖中性格不能偷换类别、撤回后的当前类、最后一格是通用针点、重复格拒绝。
- 浏览器逐格点通1A、2A、4A；检查撤回后刷新保留24/25进度；检查穿墙拒绝和提示；通过通用针点后提前换类被拒绝。
- 浏览器390px宽度实际拖动相邻格，进度由1/36增长至2/36。
- 浏览器320px宽度：6×6每格约48.7px；7×7在收紧边距后每格44px，棋盘308px、无整页横向溢出。
- 浏览器检查不等于实体手机误触率验证，八张的真人难度仍待试玩。

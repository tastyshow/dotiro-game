# 一至四关难度梯度小样

已批准设计：四关各六张；固定起点；第一关5×5全程无墙，前四张无针点、后两张引入针点；第二关6×6前两张无墙、中段直墙、末段简单L墙；第三关6×6增强通道和组合墙规划；第四关7×7，末两张原样沿用第五版C、D。

实现计划：复用规则和触控；生成22张并按分支与规划指标挑选候选，不以解数排名；导入C、D；加入关卡切换和每关六小关导航、独立续玩；检查24张合法路线、墙几何、阶段契约；浏览器检查跨关、续玩、提示与窄屏；发布独立GitHub Pages目录。

这是难度试玩入口，未把关卡接入正式作品解锁或绣画进度。图案沿用现有素材。所有合法路线均可获胜；最小触控格44px。生成指标不等同于人类难度，阶段衔接和真机误触需要试玩校准。
